# Home Credit Default Risk

## Project Overview

This repository contains my semester-long predictive analytics project based on the Kaggle Home Credit Default Risk competition.

Home Credit seeks to expand responsible lending to applicants who may have limited or no traditional credit history. The purpose of this project is to use customer and loan application data to predict whether an applicant may experience difficulty repaying a loan.

## Business Problem

Lenders must balance two important goals:

1. Providing qualified applicants with access to credit.
2. Reducing financial losses caused by loan defaults.

An effective predictive model can help Home Credit evaluate risk more consistently. However, model performance is only one part of the project. The analysis must also produce results that are understandable, useful, and actionable for business decision-makers.

## Project Objectives

The objectives of this project are to:

* Understand the Home Credit business problem and available data.
* Clean and prepare the data for analysis.
* Explore factors associated with repayment difficulty.
* Develop and compare predictive models.
* Evaluate model performance using appropriate metrics.
* Translate the results into practical business recommendations.
* Consider the fairness, limitations, and risks of using predictive models in lending.

## Data Source

The data comes from the [Home Credit Default Risk competition on Kaggle](https://www.kaggle.com/competitions/home-credit-default-risk).

The dataset includes information about loan applications, applicants’ financial and demographic characteristics, credit histories, previous applications, and repayment behavior.

Because of file-size restrictions and the competition’s data-use requirements, the original Kaggle data files will not be uploaded to this repository.
